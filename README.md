# CodeProof

Blockchain-Based Project Ownership Verification
and AI-Assisted Code Similarity Detection.

## Project Overview

CodeProof helps developers register project fingerprints
on a blockchain and identify potentially similar source code.

## Technology Stack

- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Blockchain: Solidity + Hardhat
- Database: PostgreSQL
- Code Analysis: Python + scikit-learn
